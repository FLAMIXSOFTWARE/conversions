# Conversions

Reads the visitor's analytics cookies (Yandex Metrika, Google Analytics, Facebook and TikTok Pixel) and sends conversions to the [Flamix Conversion APP](https://flamix.solutions/bitrix24/marketing/conversion.php).

## Install

```bash
composer require flamix/conversions
```
